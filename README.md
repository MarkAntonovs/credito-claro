# CreditoColombia.co rebuild

TanStack Start rebuild of [CreditoColombia.co](https://creditocolombia.co/), an independent informational and affiliate comparison site about credit options in Colombia. The application distinguishes direct credit providers from brokers, aggregators, and other intermediary services.

## Stack

- TanStack Start and TanStack Router
- React 19
- Tailwind CSS 4
- Bun
- Server-side rendering through Nitro's Cloudflare module target

## Development

```bash
bun install
bun run dev
```

The development site is globally protected from indexing. `siteConfig.indexingEnabled` must remain `false` until the legal/contact disclosures and Cloudflare launch checks are complete.

## Validation and production build

```bash
bun run format
bun run lint
bunx tsc --noEmit
bun run build
bun run validate:seo
git diff --check
```

The production build is emitted to `.output/` for the Cloudflare/Nitro deployment target.

## Architecture

- `src/routes/`: file-based TanStack routes and route-level metadata.
- `src/components/layouts/`: shared SSR page layouts.
- `src/components/site/`: reusable navigation, provider, trust, and content components.
- `src/config/`: site, route, navigation, redirect, indexability, and language-pair registries.
- `src/data/migration/`: migrated Spanish and English content, source records, and legacy URL inventory.
- `src/data/providers/`: verified provider records, provenance, profile content, sources, and the active affiliate-link registry.
- `src/lib/`: SEO, sitemap, structured-data, and server support helpers.
- `scripts/validate-seo.mjs`: compiled-worker SEO and route validation.

`src/routeTree.gen.ts` is generated by TanStack Router. Do not edit it manually; commit regenerated changes alongside route changes.

## Launch safety

Do not deploy this repository as the indexed replacement site until all of the following are complete:

- production owner, contact, privacy, and terms information is supplied and reviewed;
- the Cloudflare apex domain, `www` and HTTPS normalization, security headers, redirects, and caching are verified;
- the production build and SEO validation pass from a clean reviewed commit;
- indexing is enabled deliberately as a separate launch action.

Never enable indexing merely to test a build.
